# Backlog: raw requests

These are the requests as they came in from colleagues. They are **deliberately vague**. Don't start coding from them. Pick one, run `/grill-me` (or `/grill-with-docs`) on it, and let Claude interview you until you have a shared understanding. Then implement it.

The size is a rough guess for a pair in the workshop.

---

## 1. Paste a matrikkelnummer into search (S)

> "Caseworkers copy matrikkelnummer from letters and emails, like `0301-207/45`. Right now they have to split it up by hand into the kommune, gnr and bnr fields. Can't they just paste it in?"

## 2. Shares have to add up (S–M)

> "We found a unit where the shares add up to 3/4. That's not supposed to be possible! Make sure it doesn't happen again."

## 3. Smarter address search (M)

> "When I search for `storgt 1` or `kirkevn` I get nothing. Search should work the way people actually write. And why is it case sensitive in some places and not others?"

## 4. Ownership history (M)

> "When an owner is replaced, we lose the information about who owned the property before. We need to be able to see the history."

## 5. Export for the municipality (S)

> "Drammen kommune wants a list of all the units in their municipality with owners. They work in Excel."

## 6. Fradeling (L, good for grilling)

> "We need to be able to split off a new parcel from an existing unit. The new parcel gets its own bnr. And then something has to happen with the buildings and addresses, I suppose?"
